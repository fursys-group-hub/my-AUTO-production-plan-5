# 생산계획 수립 도구

정기 생산계획 데이터 가공을 자동화하는 단일 HTML 파일 웹앱입니다. 별도 서버나 백엔드 없이 브라우저에서 전부 동작합니다.

## 배포 주소

https://fursys-group-hub.github.io/my-AUTO-production-plan-5/

## 데이터 보관 방식

- 업로드하는 엑셀(재고 현황, 수주량, 행사 점검)과 관리 품목 코드(txt) 파일은 브라우저 안에서만 읽어 처리하며, 어디로도 전송되지 않습니다.
- 화면에 입력한 내용(요일별 수량, 목표생산량 등)은 접속한 브라우저의 `localStorage`에만 자동 저장됩니다. 즉, 각자의 컴퓨터·브라우저에만 남고 다른 사람과 공유되지 않습니다.
- 상단의 **🧹 입력 내용 초기화** 버튼으로 현재 입력값을, **🗑️ 저장 초기화** 버튼으로 자동저장된 데이터를 각각 지울 수 있습니다.

## 업데이트 방법

`index.html`을 수정해 `main` 브랜치에 푸시하면 GitHub Pages가 자동으로 재배포합니다.
