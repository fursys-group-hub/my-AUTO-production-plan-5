생산계획 입력 화면

수주량·재고현황 데이터를 합쳐 주간 생산계획표를 만드는 메인 화면입니다.

  1. 재고 현황(grd_list), 수주량(일_수주량) 파일을 업로드합니다. (관리 품목 코드 txt는 선택)
  2. 생산 기준일과 주차를 설정합니다.
  3. 계획표 생성을 클릭합니다.

→ 품목별 재고/입출고 예량, 판매예상·적정공급·기말재고 수량, 요일별(월~금) 목표생산량을 확인·수정하고, 작성용 파일 / ERP 투입 파일로 다운로드할 수 있습니다.

🧱 블록 소요량
생산계획표 입력 후 업데이트 버튼을 눌러 최신 계획수량으로 다시 계산합니다.
🧱

블록 소요량 화면

생산계획 입력 화면의 목표생산량을 기준으로 블록 자재 필요 수량을 계산합니다.

  1. 생산계획 입력 화면에서 계획표를 먼저 생성·입력합니다.
  2. 이 화면에서 업데이트 버튼을 클릭합니다.

→ 레코텍 / 엘라스틱 / 테롤 22 / 스프링 레코텍 / 스프링 엘라스틱 자재별로 사이즈(S/SS/Q/K/KK)별 소요량이 자동 계산되며, 엑셀로 다운로드할 수 있습니다.

📦 일일 수주량
수주량 파일 기준 품목별 수주 현황
📦

일일 수주량 화면

업로드한 수주량(일_수주량) 파일의 원본 데이터를 품목별·날짜별로 조회하는 화면입니다.

  1. 생산계획 입력 화면에서 수주량 파일을 업로드합니다. (이 화면과 자동으로 연동됩니다)

→ 품목코드/품목명 검색, 관리품목·재고부족 필터로 수주 현황을 빠르게 확인할 수 있습니다.

🏭 일일 재고량
grd_list 기준 품목별 일별 예량
🏭

일일 재고량 화면

grd_list 파일 기준 품목별 일자별 예상 재고(입고예량/출고예량 반영)를 조회하는 화면입니다.

  1. 생산계획 입력 화면에서 grd_list 파일을 업로드합니다. (이 화면과 자동으로 연동됩니다)

→ 생산계획 반영 업데이트를 누르면 생산계획 입력 화면에서 작성한 목표생산량이 일자별 재고에 반영되어 갱신됩니다.

📈 판매예측 매핑
판매예측 엑셀 파일은 시트/열 구성이 다양합니다. 파일을 올린 뒤 항목별로 시트·코드열(단품코드/색상/단품코드+색상)·합산할 수량열을 직접 체크해서 적용하세요.
📈

판매예측 매핑 화면

판매예측 엑셀 파일은 시트마다 열 구성이 달라 자동 인식이 불안정해, 항목별로 시트와 열을 직접 체크해 매핑합니다.

  1. 판매예측 엑셀 파일을 업로드합니다. (여러 시트를 포함한 워크북 전체)
  2. 판매예상수량 / 적정공급수량 / 기말재고수량 각 항목마다 시트를 선택합니다.
  3. 미리보기 표에서 코드열(단품코드, 색상, 또는 단품코드+색상 결합) / 합산할 수량열을 체크합니다.
  4. 각 항목의 매핑 적용을 클릭합니다.

→ 생산계획 입력 화면에 판매예상수량 / 적정공급수량 / 기말재고수량 열이 코드(+색상)별 합산값으로 표시되어 자동 반영됩니다.
